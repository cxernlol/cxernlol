### Core beliefs

* **Paid implies a free path** — if the free one doesn't exist or is trash, that's my backlog.
* **Electron vs hardware** — if boot beats the OS, it's broken.
* **Subscriptions for local tools are a scam** — own the hardware, own the software.
* **Open source or bust** — audit, build, strip tracking, or don't trust it.
* **"Works on my machine"** — environment failure, not a punchline.

### Daily routine

1. Write ~50 lines of Rust (or wire an agent to the right MCP).
2. Spend 45 minutes on lifetime annotations.
3. Find the bug was a typo on line 4.
4. Push at 3:42 AM with a commit message HR bots would flag.
